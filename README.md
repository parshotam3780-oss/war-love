# WAR LOVE Tournament

A dark, cinematic gaming tournament website for the **WAR LOVE Free Fire Championship** — built with TanStack Start, React, and Tailwind CSS v4.

## Features

- **Full Free Fire theme** — dark crimson + deep purple color palette, ember particle effects, flame decorations, scan-line overlay
- **Custom SVG logo** — crosshair shield with animated flame and WL monogram
- **Live countdown timer** — counts down to the Grand Final
- **Sections**: Hero · Stats · Battle Timeline · Top Squads · Prize Pool · App Download · Squad Registration
- **Download CTAs** for iOS and Android apps
- **Squad registration form** with real-time validation
- **Responsive** mobile-first layout

## Tech Stack

- [TanStack Start](https://tanstack.com/start) (React SSR/SPA framework)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Vite](https://vitejs.dev/)
- Deployed on [Netlify](https://netlify.com)
- Google Fonts: Bebas Neue, Rajdhani, Orbitron

## Running Locally

```bash
npm install
npm run dev
```

The dev server starts at `http://localhost:3000`.

For full Netlify feature emulation (functions, edge, etc.):

```bash
netlify dev --port 8889
```
